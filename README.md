# ⚡ CodePulse — Programming Tips Blog

A static blog about programming tips and web development, built with plain HTML & CSS. No frameworks, no dependencies — just the web platform.

**Live site:** `https://<your-username>.github.io/devtips-blog/`

## 📄 Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — post list and featured article |
| `about.html` | About the author |
| `posts/post1.html` | CSS Tips post + embedded video |
| `posts/post2.html` | Final reflection + reader comments |

## 🚀 Deploy to GitHub Pages

1. Create a new repository on GitHub
2. Upload all files (keep the folder structure)
3. Go to **Settings → Pages → Source → main branch → / (root)**
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

## 🛠️ Built With

- HTML5 + CSS3 (no frameworks)
- CSS Custom Properties for theming
- Flexbox & CSS Grid for layout
- Mobile-responsive design
- YouTube embed (iframe)
