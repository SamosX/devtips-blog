5 CSS Tips That Will Change the Way You Write Styles

October 2026 3 min read Web Development

CSS can feel overwhelming at first — especially when your stylesheets start growing into hundreds of lines. But with a few modern techniques, you can write styles that are cleaner, easier to maintain, and more powerful. Here are 5 CSS tips every web developer should know.

1. Use CSS Custom Properties (Variables)

Instead of repeating colors, font sizes, or spacing values throughout your CSS, define them once as variables inside :root. This makes it incredibly easy to update your entire design from a single place. 

:root {
  --primary: #6c63ff;
  --text: #e2e8f0;
  --spacing: 1.5rem;
}

button {
  background: var(--primary);
  padding: var(--spacing);
  color: var(--text);
}

If you ever want to change your brand color, you update it in one line instead of searching through your entire file.

2. Master Flexbox for Layouts

Flexbox is one of the most useful CSS tools for building layouts. Use it to center elements, distribute space, and create responsive navigation bars with minimal code. 

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
}

/* Center anything */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}
Quick rule: Use justify-content for horizontal alignment and align-items for vertical alignment (in a row-direction flex container).

3. Use clamp() for Responsive Typography

Instead of writing multiple media queries just to change font sizes, use clamp() to let the browser calculate a fluid size between a minimum and maximum value. 

h1 {
  /* min: 1.5rem | preferred: 4vw | max: 3rem */
  font-size: clamp(1.5rem, 4vw, 3rem);
}

Your heading will scale smoothly with the viewport — no media queries needed.

4. Use :is() to Simplify Selectors

The :is() pseudo-class lets you group multiple selectors together, reducing repetition and making your CSS easier to read. 

/* Instead of this: */
h1 a, h2 a, h3 a { color: inherit; }

/* Write this: */
:is(h1, h2, h3) a { color: inherit; }

5. Smooth Scroll with One Line

Add smooth scrolling to your entire page without a single line of JavaScript: 

html {
  scroll-behavior: smooth;
}

Now all anchor links (<a href="#section">) will scroll smoothly instead of jumping instantly.
