Reflection

What I Learned Building This Blog from Scratch

October 2026 2 min read Final Post · Stage 3

This is the final post of CodePulse, and it feels significant to write it. What started as a school project quickly became a genuine learning experience that pushed us further than expected. Here is an honest look at what we built, what broke, and what we took away from it all.

What We Learned

Building a blog from pure HTML and CSS — without WordPress or any template — forced us to understand how the web actually works. We learned how to structure pages semantically, how CSS custom properties make design systems manageable, and how responsive design is not just about making things smaller, but about rethinking layout entirely.

Writing posts in English also challenged us to communicate technical ideas clearly and concisely — a skill that matters just as much as the code itself.

Challenges We Faced

  • Getting the navigation to stay sticky without breaking the layout on mobile.
  • Making the video embed scale properly on all screen sizes using aspect-ratio.
  • Writing content that is both accurate and easy to understand for readers at any level.
  • Keeping the design consistent across multiple HTML pages without a framework.
Key insight: The hardest part of building a blog is not the code — it is deciding what to say and making sure it actually helps someone.

How the Blog Evolved

The first version of this blog was a plain page with basic styles. Over time, we added a dark theme, a sticky navbar, card layouts, animated sections, a code window visual, and a proper post format with code blocks and video embeds. Each change taught us something new about CSS and about how design affects the reader's experience.

Looking Forward

We want to keep CodePulse active beyond this project. There are topics we did not cover — JavaScript async patterns, CSS Grid, and mobile-first design — and we would like to share them here. This project reminded us that the best way to solidify knowledge is to explain it to others.

Thank you for reading. If any of these posts helped you, that is exactly what CodePulse was built for.
